# Hackathon Live Demo & Presentation Script

## Demo Duration: 3 Minutes

### 1. Introduction & Problem Statement (0:00 - 0:45)
- **Presenter:** "Scholarship applications are notorious for complex, multi-page criteria. Students often get rejected not because they lack merit, but because they missed a single requirement or submission detail."
- **Visual:** Show the Streamlit Upload Screen (`app.py`).
- **Presenter:** "Our system solves this by automatically reading official scholarship guidelines, matching uploaded student files against each rule, and pinpointing exact gaps."

### 2. Live Application Ingestion & Readiness Analysis (0:45 - 1:45)
- **Action:** Drag and drop `sample_documents/scenario_2_missing_docs/` into the upload zone and click **Analyze Readiness**.
- **Visual:** Point out the real-time `st.status` progress steps emitted by Member 6's orchestrator (`agents/orchestrator.py`).
- **Presenter:** "Notice how our orchestrator processes documents in real time. In under 3 seconds, we receive a structured **Readiness Report**."
- **Visual:** Highlight the **75% Readiness Score**, the verified GPA from `transcript.txt`, and the red **MISSING** status on the *Recommendation Letter*.

### 3. Action Center & Automated Generation (1:45 - 2:30)
- **Action:** Click the expander under the missing Recommendation Letter rule showing evidence: *"Section 2.3 - Mandatory Recommendation Letter."*
- **Action:** Click **Generate Recommendation Request Email**.
- **Visual:** Show the auto-drafted email template generated by Member 4's LLM agent.
- **Presenter:** "Instead of leaving the student stuck, our Action Center generates tailored draft artifacts using only verified facts from the applicant's existing profile."

### 4. Architecture & QA Wrap-Up (2:30 - 3:00)
- **Visual:** Display `docs/architecture.md` / Architecture Diagram.
- **Presenter:** "Under the hood, we have a modular 6-agent system covering RAG retrieval, document classification, deterministic gap evaluation, and full state orchestration. All components are covered by end-to-end integration tests in `tests/test_integration.py`."
- **Closing:** "Thank you! We are open to questions."
